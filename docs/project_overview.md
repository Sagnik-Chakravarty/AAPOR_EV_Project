# Project Overview

## Electric Vehicle Public Sentiment: LLMs vs. Digital Trace Data

This project evaluates whether large language models can approximate observed public sentiment about electric vehicles. It compares LLM-generated sentiment estimates with sentiment signals from digital trace data, including Reddit communities and news sources.

The project was selected for presentation at the 80th Annual AAPOR Conference.

## Research Motivation

LLMs can generate plausible statements about public opinion, but those outputs are not necessarily grounded in observed public discourse. This creates an important measurement question for survey research, market research, and computational social science: can LLM-generated sentiment serve as a valid proxy for real-world public opinion, or does it smooth, distort, or miss platform-specific discourse patterns?

This project treats LLM sentiment as one measurement source and compares it with observed digital trace sentiment from online communities and news coverage.

## Research Questions

1. How does LLM-generated electric vehicle sentiment compare with observed sentiment from digital trace sources?
2. Do different online sources produce different sentiment profiles?
3. Where do LLM sentiment estimates diverge from platform-specific observed discourse?
4. What does this imply for using LLMs as substitutes or supplements for survey-adjacent public opinion measurement?

## Main Contributions

- Builds a multi-source sentiment comparison around electric vehicle discourse.
- Compares LLM-generated sentiment with observed digital trace sentiment.
- Uses Reddit community-level data to examine platform and subgroup differences.
- Produces visual and statistical summaries of sentiment variation.
- Frames the project as a measurement-validity problem relevant to survey methodology and public opinion research.

## Main Outputs

- LLM sentiment output files.
- Reddit sentiment datasets by subreddit/community.
- Cleaned sentiment summary tables.
- R/Quarto visualization workflows.
- Statistical comparison workflow.
- AAPOR-ready project framing and interpretation.
