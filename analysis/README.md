# Analysis

This directory is reserved for cleaned and renamed analysis workflows.

The current project analysis is stored in the original project directory:

```text

```

Key workflows include:

- LLM sentiment generation and cleaning,
- Reddit scraping and sentiment aggregation,
- news data processing,
- statistical comparison of sentiment summaries,
- visualization of LLM and Reddit sentiment outputs.
